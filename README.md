# dethariyanikunj.github.io

Personal Portfolio SPA for **Nikunj Dethariya** — Senior Mobile Engineer & Flutter Architect (10+ Years Mobile Engineering). Built with React, Vite, TypeScript, Tailwind CSS, and Framer Motion.

## Features
- **Midnight Obsidian & Cyber-Luxe Glassmorphism Theme**
- **Data-Driven Architecture**: All profile content, technical skills, experience, awards, education, and projects configured in `src/data/portfolio.ts`
- **Responsive Layout**: Optimized for mobile, tablet, and desktop viewports
- **Fast Build**: Vite + TypeScript compilation

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## GitHub Pages Deployment

1. Push to `main` branch.
2. Workflow `.github/workflows/deploy.yml` will automatically build and publish to GitHub Pages.
3. Live URL: `https://dethariyanikunj.github.io/`
